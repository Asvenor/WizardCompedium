# Table structure audit

Reviewed the 350 original chapter tables at revision 22e4d71. This is a targeted source-content pass, not a conversion pipeline.

- A — genuine comparison, data, decision, progression, or compact legend: 316.
- B — layout container, explanation, warning, or checklist: 25.
- C — mixed comparison plus misplaced explanation/metadata: 9.
- 35 original tables improved; 315 left structurally unchanged.

## Decisions

Chapter 11: replace the ownership grid with 10 spell-level pools (144 spell rows); replace the choice grid with 9 level headings, 27 category subheadings, and 76 individual spell rows. Repeat a shared purpose only with an explicit shared-guidance label; retain the original shared names and explanation immediately below its category. Source/selectability conditions, acquisition rules, and the four strategy lanes remain visible outside tables. Spell links resolve only to existing canonical records; Alarm and Divination have no standalone record and remain plain text.

Chapter 10: retain the 20-step progression matrix, promote its real four headings, remove empty layout columns, and move the build-code legend outside. Keep route clauses as lists with their original punctuation so the level-up assistant continues reading the same recommendations. Chapter 4: retain the meaningful level/milestone comparison and separate route deltas as real list items.

Chapters 22, 23, 24, 50, 56: replace 15 standalone warning/rules containers with the existing visible callout pattern at their original positions. No disclosures or hover-only restrictions.

Chapter 31: move the green-light gate before the six copying steps and promote Step / Pass gate / Active rule / Stop / failure to actual column headers.

Chapter 54: move seven build descriptions and source statuses above their comparisons. Replace seven loadout layout grids with Prepared overlay, Attunement / gear, and Rest audit subsections; keep each Table check attached to that build. Turn scripts and encounter comparisons remain unchanged.

Short spell tables explicitly opt into a compact responsive style. Wide matrices retain keyboard-focusable scroll containers. The first column is no longer automatically bolded when it contains prose. Existing section headings/anchors and source-locator comments are retained.

## Preservation and verification

The fidelity audit still requires the existing 99.5% per-block threshold. Its tokenizer now recognizes Word's joined heading/prose boundaries (for example LIMITThis and Pure 1Dip 2), identically in input and output; no blocks are excluded and no coverage threshold is lowered. A dedicated regression test verifies all choice-map spell/category/purpose associations and all 20 progression entries against the pre-edit content.

No canonical spell metadata, rankings, hosting, authentication, search architecture, or profile storage changed. No missing metadata was inferred from general D&D knowledge.
