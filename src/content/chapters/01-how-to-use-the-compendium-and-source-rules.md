## Source access and rules handling

<!-- source:B00018 -->
This compendium uses the active D&D Beyond character builder as its campaign-legality engine: if the exact option can be selected, it is green-lit. The verified configuration enables 5.5e Core Rules, 5.5e Expanded Rules, 5e Core Rules, 5e Expanded Rules, and purchased Partnered Content. Homebrew, D&D Beyond Drops, and Legacy/Noncore are disabled. When the builder exposes more than one distinct version, record the version chosen on the character; the active entry controls its rules text. This compendium is a fixed universal reference, not a write-in workbook; character-specific state belongs in D&D Beyond or separate campaign notes.
