Rarity color is a retrieval aid, not a power rating: an Uncommon item can be more useful to this Wizard than a Legendary item. Rarities and wording use the 2024 SRD 5.2.1 where the item appears; Arcane Grimoire is an enabled Tasha's expanded-source item when selectable. Mundane gear stays neutral because the magic-item rarity ladder does not apply to it.

## Magic-item review filter

<!-- source:B00429 -->
Use this filter before adding an unfamiliar item to the main watchlist or committing an attunement slot.

<!-- source:B00430 -->
<div class="table-wrap" data-source-locator="B00430.T001" tabindex="0"><table><thead><tr><th scope="col">Effect to look for</th><th scope="col">Add it when...</th></tr></thead><tbody><tr><td>Spell save DC</td><td>Top priority. A DC increase improves the control spells that define the build.</td></tr><tr><td>Concentration / saves</td><td>High priority when it prevents losing the encounter-winning spell or covers a weak save.</td></tr><tr><td>Initiative / awareness</td><td>High priority for Chronurgy, Diviner, and any controller that wants the first meaningful turn.</td></tr><tr><td>Slot recovery / free casting</td><td>High priority if it adds real daily resources without consuming the same attunement slot as a stronger core item.</td></tr><tr><td>Mobility / escape</td><td>High priority in small parties or terrain-heavy campaigns; flight and teleportation can be stronger than damage.</td></tr><tr><td>Armor / Shield / reaction defense</td><td>Compare against the current AC, reaction economy, and concentration plan. Do not chase AC that costs the action or reaction needed to control.</td></tr><tr><td>Tools / scrolls / spellbook</td><td>Artificer and downtime builds value tool bonuses, crafting support, cheaper copying, scroll use, and extra prepared flexibility.</td></tr><tr><td>Weapon-only damage</td><td>Usually low priority for normal Wizards. It rises only for a Bladesinger plan that still preserves Wizard-first casting.</td></tr></tbody></table></div>

## Three-slot attunement logic

<!-- source:B00434 -->
<div class="table-wrap" data-source-locator="B00434.T001" tabindex="0"><table><thead><tr><th scope="col">Slot purpose</th><th scope="col">Generic controller</th><th scope="col">Bladesinger</th><th scope="col">Tank / armored Wizard</th></tr></thead><tbody><tr><td>1. Spell power</td><td>Spell-save DC / spell attack improvement.</td><td>Spell-save DC remains the default unless the weapon package truly changes the campaign.</td><td>Spell-save DC remains core because control is still the tanking engine.</td></tr><tr><td>2. Defense</td><td>General saves, concentration, or strong defensive item.</td><td>AC, saves, concentration, or movement.</td><td>General saves, concentration, armor-compatible defense.</td></tr><tr><td>3. Flex slot</td><td>Initiative, mobility, slot recovery, utility.</td><td>Mobility or weapon support that does not weaken casting.</td><td>Initiative, mobility, or party protection.</td></tr></tbody></table></div>

<aside class="callout" data-source-locator="B00434.T002"><strong>ATTUNEMENT RULE</strong><p>An individually powerful item can still be wrong if it displaces a stronger complete three-slot package. Rate items by the slot they replace, not only by their isolated effect.</p></aside>

## Non-attunement mission kit

<!-- source:B00439 -->
These items preserve all three attunement slots. Their value is operational: they solve storage, movement, communication, detection, escape, and base logistics without displacing spell DC or defense.
