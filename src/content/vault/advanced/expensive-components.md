Expensive spell components have distinct tactical and economic roles.

**Consumed** components are recurring costs.  
**Retained** components are investments you usually buy once.

## Important Wizard Components

These are minimum listed values, not guaranteed shop availability. Rows from expanded sources still require access to that spell. A focus or Component Pouch cannot replace a component with a specified price.

\*Magic Jar's receptacle is not consumed at the initial casting, but **is destroyed when the spell ends**. Its minimum 500 GP is therefore an eventual replacement cost, not an indefinitely reusable focus.

**Instant Summons** uses a different sapphire for each object. Crushing it to invoke recall spends it even when a creature carrying the object prevents retrieval; see the card for the fallback information benefit. Reusable summon components are distinct items: a 400 GP Construct lockbox does not also count as an Aberration vial merely because their prices match.

## Buying Priority

1. Components that unlock a spell you already expect to cast.
2. Reusable components with repeated value.
3. Mission-specific consumed components.
4. High-level infrastructure components only when the project is real.

## Component Cache

Keep rare reusable components separate from your everyday coin.

A high-level cache can include:

- Plane Shift forks
- Contingency statuette
- Scrying focus
- Summon spell foci
- Shapechange focus
- Clone vessel
- Backup spellbook

Always verify the active spell entry before spending large amounts of gold.
