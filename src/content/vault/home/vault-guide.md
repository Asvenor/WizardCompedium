## Find the right reference

- [Spell Progression Hub](/library/character/spell-progression-hub/) gives **36 self-contained no-copy spell progressions**: 35 core routes across seven subclasses and five class plans, plus an optional pure Illusionist/Illusion Adept feat configuration. Each has exact acquisitions, subclass extras, cantrips, and preparation examples; [Multiclass Spell Timing](/library/character/multiclass-spell-timing/) explains the class-level and spell-slot boundaries.

- [Worked Wizard Builds](/library/character/worked-wizard-builds/) gives four complete static level-1–20 examples; [Build Decision Engine](/library/character/build-decision-engine/) compares class dips, feats, and opportunity costs; [Level Progression Planner](/library/character/level-progression-planner/) gives the generic progression table.
- [Arcana Unleashed Builds](/library/character/arcana-unleashed-builds/) supplies three static Conjurer, Illusionist, and Necromancer examples, legal spellbook choices, and prepared examples; [Arcana Unleashed Combinations](/library/tactics/arcana-unleashed-combinations/) explains their interaction limits. These examples do not replace the equally presented pure/dip routes in the progression hub.
- [Summon Damage Benchmarks](/library/tactics/summon-damage-benchmarks/) compares equal-slot companion packages with accuracy, critical hits, and setup turns included.
- [Spell Finder](/library/home/spell-finder/) filters spell rules and tactical roles; [Prepared Loadouts](/library/tactics/prepared-loadouts/) compares candidate choices by mission.
- [Item Finder](/library/home/item-finder/) filters magic-item choices by rarity, attunement, source, and role; [Magic Item Attunement](/library/items/magic-item-attunement/) compares complete equipment packages.
- [Combat Dashboard](/library/tactics/combat-dashboard/) summarizes encounter decisions; [Problem Navigator](/library/home/problem-navigator/) routes specific obstacles to tactics.
- [Form Catalogue](/library/creatures/form-catalogue/) distinguishes creature capabilities and legal transformation routes.
- [Wizard Operations Roadmap](/library/advanced/wizard-operations-roadmap/) explains long-term power, costs, prerequisites, and failure conditions.

This is a reference compendium. No character profile, inventory, preparation tracking, or campaign data entry is required.

The only supported subclasses are **Abjurer, Bladesinger, Chronurgy, Conjurer, Diviner, Illusionist, and Necromancer**, in alphabetical order. Every subclass supports pure Wizard, Artificer 1, Cleric 1, Fighter 1, and Fighter 2. No build is a flagship or recommended default; use the stated payoffs, delays, source permissions, and campaign constraints to choose between them. General spell schools, feats, and monster forms are reference material, not additional build variants.

## Add information consistently

Templates live in the existing Inbox area, under Templates. Use the core Templates command to insert one into a new empty note. Choose a unique descriptive title; a new spell card uses “Spell name - Spell” and a creature uses “Creature name - Creature”. Keep the original official title in the name property.

- [Spell Template](/library/inbox/templates/spell-template/) — one canonical card with casting fields and source.
- [Creature Template](/library/inbox/templates/creature-template/) — source-specific body and eligibility gates.
- [Tactic Template](/library/inbox/templates/tactic-template/) — setup, payoff, counters, and exact prerequisites.

Add each note to its nearest hub and link the relevant source. Live filters update from properties; keep the static index aligned when adding or renaming a card.

## Data ownership

Properties are hidden throughout the vault using Settings → Editor → Properties in document → Hidden. Only reference metadata is used for the filters; no personal tracker fields are required. If you ever want the panels back, choose Visible in that setting. Raw Source mode can still expose the underlying YAML. The small wizard-tools snippet adjusts table spacing and reading width; disable it in Settings → Appearance → CSS snippets to remove those display tweaks. Your ITS theme is retained.

Spell and item cards drive the filtered views. Keep one authoritative location for each set of details and link to it from tactical notes. Item cards route to the fuller item reference for restrictions and version-specific wording. Where a long reference note conflicts with a card, follow the specific official source and the visible rules clarification, not an unsupported ranking or assumption.
