**Price the ability increases as well as the Origin feat**

Acolyte increases INT/WIS/CHA, not CON or DEX. It cannot turn the common INT 15 / CON 15 array into INT 17 / CON 16 using its own background increases. Its Cleric spell access can still be useful, but compare that benefit with a background that supports the desired defensive score. [2024 Acolyte](https://www.dndbeyond.com/sources/dnd/br-2024/character-origins#Acolyte).

## Arcana Unleashed backgrounds

Compare the **whole package**, not just the feat. These are additional official options, not automatic permission to combine one background's feat with another's ability increases. See [Arcana Unleashed — Origin feats](/library/tiers/feats-epic-boon-tier-list/#arcana-unleashed--origin-feats) for the feat benefits and restrictions.

| Priority | Background | Ability choices | Origin feat | Wizard assessment |
|---|---|---|---|---|
| S/A | **Agent of the Ninth Quill** | DEX / INT / CHA | Arcane Infiltrator | INT-compatible with Bonus Action Dodge, Arcana/Sleight of Hand and Thieves' Tools. Excellent defense/infiltration, but cannot directly raise CON. |
| A, familiar route | **Familiar Trainer** | CON / INT / WIS | Familiar Friend | Excellent defensive stat pairing, Arcana and a durable companion. Animal Handling is a more situational second skill. |
| A/B | **Seer Apprentice** | INT / WIS / CHA | Arcane Omens | Useful party save correction and Guidance. Like Acolyte, does not supply a DEX/CON increase. |
| B, mobility route | **Horizon Weaver Initiate** | DEX / CON / WIS | Portal Jumper | Strong resistance/teleport package, but no INT increase; compare later INT progression against Criminal or an allowed custom background. |
| B/C, resilience route | **Cosmic Dawn Experiment** | STR / DEX / CON | Transmuted Anatomy | CON-save correction and movement help; no INT and no Arcana proficiency in the package. |
| C, specialist | **Covenant of the Grave Recruit** | STR / INT / WIS | Arcane Undertaker | History/Medicine and death-related utility, not a direct Necromancer army boost. |
| C | **Crucible Storm Chaser** | STR / CON / INT | Arcane Overload | Good INT/CON compatibility, but a small once-per-Long-Rest damage rider is a weak reason to choose it over stronger defense/control origins. |
| C, social route | **Bejeweled Conclave Spy** | DEX / WIS / CHA | Arcane Eloquence | Stronger social checks plus Deception/Perception; no INT increase. Compare the value of a social-infiltration role with the ability-score cost for the chosen Wizard build. |
| C, performance route | **Phantasmic Circus Trouper** | DEX / CON / CHA | Arcane Artist | Illusion-themed Inspiration support, but no INT increase and only one Inspiration grant per Long Rest from the feat. |
| C, support route | **Ward of the Sheltering Hands** | CON / WIS / CHA | Arcane Safeguard | Helpful support flavor and CON access; no INT and its Resistance cantrip competes for Concentration. |

**Default comparison:** Criminal remains attractive for INT/CON/DEX and Alert; Familiar Trainer trades first-round priority for companion durability, while Agent of the Ninth Quill trades CON access for active Bonus Action defense. There is no source-independent single best background.

Source: [Arcana Unleashed backgrounds](https://www.dndbeyond.com/sources/dnd/au/chapter-1-character-options#Backgrounds). Custom background availability and construction remain DM-controlled, not an unrestricted player entitlement.
