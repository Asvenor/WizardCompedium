# Which Transformation Spell?

| Goal | Use |
|---|---|
| **Give an ally a strong Beast body** | [[Polymorph]] |
| **Temporary HP buffer / combat transformation** | [[Polymorph]] — not healing; form ends when its granted buffer runs out |
| **Become a powerful creature while retaining core Wizard capabilities** | [[Shapechange]] |
| **Switch between forms during one spell** | [[Shapechange]] |
| **Transform another creature into a powerful creature** | [[True Polymorph]] |
| **Create a CR ≤9 creature from an object** | [[True Polymorph]] |
| **Create a long-term transformed asset** | [[True Polymorph]] |
| **Turn a creature into an object** | [[True Polymorph#Creature → Object]] |

# Fast Decision Tree

**Do I want to transform myself?**

→ [[Polymorph]] for a temporary Beast body from spell level 4; [[Shapechange]] at spell level 9 when retaining core Wizard capabilities matters.

**Do I want to temporarily transform an ally into a Beast?**

→ [[Polymorph]]

**Do I want to transform another creature into something much more powerful?**

→ [[True Polymorph]]

**Do I want to manufacture a creature from an object?**

→ [[True Polymorph#Created Utility Assets]]

**Do I need a long-term creature or servant?**

→ [[True Polymorph]] can make an ongoing creature, but its initial control does not continue after the full hour. [[Planar Binding]] supplies time-limited service by an eligible existing creature, not permanent loyalty.

**Do I need scouting rather than combat?**

→ [[Find Familiar]]

**Do I need a specific extraplanar servant?**

→ [[Planar Binding Candidate]]

**Do I need transportation?**

→ [[Planar Binding Mount]] or the relevant transformation movement section.
