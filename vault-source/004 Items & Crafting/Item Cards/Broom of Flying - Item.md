# Broom of Flying

[[Item Finder]] · [[Magic Item Attunement]] · [[Magic Item Tier List]]

**Uncommon · Attunement required · Dungeon Master's Guide (2024)**  
**Access:** No class restriction

## Practical value

Magic action starts ridden flight: Fly 50, reduced to 30 above 200 lb.; maximum 400 lb.

## Limiting cost

The 2024 version requires attunement. It stops hovering when landed or no longer ridden; do not import the legacy non-attunement version.
